# Bank-Marketing-SQL-Analysis
SQL analysis of a Portuguese bank's telemarketing campaign — exploring which customer profiles and contact strategies drive term deposit subscriptions.

# Bank Marketing SQL Project

## Overview
This project analyzes a Portuguese bank's telemarketing campaign data using SQL. 
The dataset tracks client demographics, loan/credit status, contact details, and 
economic indicators to understand what drives clients to subscribe to a term deposit.

## Tables
- bank_marketing

## Dataset
Source: [UCI/Kaggle Bank Marketing Dataset](link) — Moro et al., 2014
~41,000 client records from a Portuguese bank's telemarketing campaigns (May 2008 – Nov 2010).

## Database Structure
The project uses a single table:
- `bank_marketing` — client demographics, campaign contact details, loan status, 
  economic indicators, and subscription outcome

### Aggregation

### Intermediate SQL
- CASE statements
- Subqueries

### Advanced SQL
- Window functions (RANK, SUM() OVER, etc.)

## Business Questions Answered
- Which job types and education levels have the highest subscription rate?
- Does call duration correlate with a successful subscription?
- Which month/day-of-week had the most successful campaigns?
- What's the subscription rate for clients with vs. without existing loans?
- How does previous campaign outcome affect current subscription likelihood?
